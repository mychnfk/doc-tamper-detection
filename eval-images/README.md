# eval-images/README.md — 评测集制作指引

目标 13-15 张，目录即标签（normal=负样本，其余=篡改正样本）。

| 目录 | 内容 | 数量 | 来源 |
|---|---|---|---|
| normal | 未修改的真实单据（脱敏） | 3-4 | 业务组员提供（立刻发起收集！） |
| amount | PS 修改金额 | 2-3 | 自制 |
| date | PS 修改日期 | 2 | 自制 |
| seal | PS 拼接/替换印章 | 2 | 自制 |
| aigc | AI inpaint 重绘区域 | 2 | 即梦/SD inpaint |
| copymove | 复制粘贴条目 | 2 | 自制 |

制作规则（两档手艺，缺一不可）：
1. **粗改**每类 1 张：肉眼可对照，演示直观。
2. **精改**每类 1 张：字体贴合、边缘羽化——指标才可信。
3. 保存格式与原件一致（jpg 存 jpg，quality≥90），**绝不缩放**（坏噪声指纹=评测作废）。
4. 每张篡改图在文件名记录改动点，如 `amount_5000to50000_fine.jpg`。
5. 原件留档 `_orig` 后缀放同目录（评测脚本按前缀去重跳过 `_orig`）。

## 数据安全与脱敏（务必先读）

本仓库为 GitHub 公开仓库；图片文件已被 .gitignore 屏蔽不会入库，但样张仍会在本机与评测流程中使用，脱敏必须彻底。脱敏须覆盖：户名/账号/卡号/身份证号/手机号/地址/公章中的公司全名等一切可识别信息，遮盖或替换均可。注意：涂抹遮盖本身会被检测器当成篡改痕迹——normal 样张请尽量选"原生无敏感信息的单据"，或用裁剪构图把敏感区排除在画面外，而不是事后 PS 涂抹。

## 灰区图（决赛关键，务必满足）

现有 3 张金丝雀图全局分均未落入 0.4-0.7 灰区，"灰区触发 investigate"目前只有间接证据——而灰区图触发 Loop 放大改判是决赛演示的核心桥段。**本批评测集须包含 ≥1 张篡改图的全局分落在 0.4-0.7。**

- 制作方向：小面积、精细手法的改动（精改档）最容易落灰区；改动越大越明显，分数越容易冲出灰区上沿。
- 制作后用 `scripts/smoke_agent.py` 或 `evaluate.py`（Task 10 产出）实测 score，确认落区；不达标就调整改动幅度重做。
